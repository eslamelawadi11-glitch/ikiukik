# تقرير شامل: منصة إدارة التعليم (EduSaaS)

## 1. نظرة عامة على المشروع (Project Overview)
منصة **EduSaaS** هي نظام إدارة تعليمي متكامل مبني كخدمة سحابية (Software as a Service - SaaS). يهدف النظام إلى توفير بيئة رقمية شاملة لإدارة المدارس والمراكز التعليمية. أهم ما يميز النظام هو معمارية **تعدد المستأجرين (Multi-tenant)**، مما يعني أن منصة واحدة يمكنها استضافة بيانات مئات المدارس بشكل منفصل وآمن تماماً، حيث يمتلك كل "مستأجر" (مدرسة) بيئته الخاصة به.

## 2. الهيكلية التقنية (Architecture & Technology Stack)

### واجهة المستخدم (Front-end)
تم بناء واجهة المستخدم لتكون سريعة، متجاوبة، وسهلة الاستخدام للمديرين والمدرسين وأولياء الأمور.
* **إطار العمل الأساسي:** Vue.js 3 باستخدام Vite.
* **إدارة الحالة (State Management):** Pinia.
* **التوجيه (Routing):** Vue Router لدعم التوجيه الديناميكي للمقاطع المختلفة.
* **التصميم والتنسيق:** Tailwind CSS لتصميم عصري ومتجاوب (Responsive).
* **التواصل مع الخوادم:** Axios لإرسال واستقبال البيانات من الـ API.
* **نظام التصاريح:** يعتمد على الـ Roles (مثل Admin, Teacher, Parent, Staff) للتحكم في الصلاحيات.

### البنية التحتية للخوادم (Back-end)
النظام الخلفي مبني لتحمل الضغط العالي وقابلية التوسع (Scalability).
* **إطار العمل:** .NET (ASP.NET Core Web API) باستخدام لغة C#.
* **التصميم المعماري:** معمارية نظيفة (Clean Architecture) مقسمة لطبقات:
  * `API`: نقاط الوصول للواجهة الأمامية.
  * `Application`: منطق العمل (Business Logic).
  * `Domain`: الكيانات الأساسية (Entities) مثل الطالب، المعلم، الفصول.
  * `Infrastructure`: التعامل مع قاعدة البيانات والخدمات الخارجية.
* **المصادقة والأمان:** JSON Web Tokens (JWT) لتأمين الـ APIs، مع دعم الـ Refresh Tokens وتسجيل الدخول عبر Google.
* **تعدد المستأجرين:** يتم فصل البيانات عن طريق `X-Tenant-Id` و `TenantId` في قاعدة البيانات.

## 3. الوحدات والنظام التشغيلي (Core Modules)

تتكون المنصة من مجموعة من الوحدات (Modules) المتكاملة التي تدير الجوانب الأكاديمية والمالية والإدارية للمدرسة:

### أ. الإدارة الأكاديمية (Academic Management)
1. **الفصول (Classes):** إنشاء الفصول الدراسية وتحديد المستوى الدراسي (Grade Level).
2. **الطلاب (Students):** تسجيل بيانات الطلاب وإدارة تسجيلهم في الفصول الدراسية (Student-Classes).
3. **المعلمون (Teachers):** تسجيل وتعيين المعلمين، وربطهم بالفصول التي يقومون بتدريسها (Teacher-Classes).

### ب. التواصل والمتابعة (Communication & Monitoring)
1. **أولياء الأمور (Parents):** تسجيل بيانات أولياء الأمور وربطهم بأبنائهم (Parent-Students) لمتابعة حالتهم بانتظام.
2. **الإشعارات (Notifications):** إرسال تنبيهات مخصصة (مثال: تنبيهات للطلاب أو أولياء الأمور أو المعلمين).
3. **الحضور والغياب (Attendance):** تسجيل ومتابعة الحضور اليومي للطلاب في كل فصل دراسي.

### ج. التقييم والامتحانات (Assessment)
1. **الامتحانات (Exams):** جدولة الامتحانات، وتحديد تواريخها، وتحديد الحد الأقصى للدرجات لكل امتحان حسب الفصل.
2. **النتائج (Exam Results):** تسجيل ورصد علامات الطلاب لكل امتحان وإصدار التقارير للطلاب وأولياء الأمور.

### د. الإدارة المالية (Financial Management)
1. **المصروفات (Fees):** تتبع مدفوعات الطلاب للمصروفات المدرسية، وحالة الدفع (Status)، وتواريخ الاستحقاق (Due Date).

## 4. نظام الصلاحيات والمستخدمين (Roles & Permissions)
النظام يعتمد على 4 أدوار رئيسية للتحكم في الوصول:
1. **مدير النظام (Admin):** لديه صلاحيات كاملة لقراءة، إضافة، تعديل، وحذف البيانات في جميع الوحدات.
2. **الموظفون (Staff):** صلاحيات إدارية قوية لمساعدة الإدارة في تنظيم المنصة (مشابهة للمدير باستثناء بعض الصلاحيات الحساسة).
3. **المعلمون (Teacher):** صلاحيات مخصصة للوحدات الأكاديمية مثل تسجيل الحضور وإضافة الامتحانات والنتائج.
4. **أولياء الأمور/الطلاب (Parent/Student):** صلاحيات قراءة فقط لمتابعة البيانات الخاصة بهم (مثل النتيجة، الحضور، الإشعارات، الرسوم).

## 5. ملخص وقيمة المشروع
تعتبر منصة EduSaaS حلاً رقمياً متقدماً يستهدف تبسيط الإدارة المدرسية وتحويلها إلى نظام لا ورقي (Paperless). من خلال اعتماد نموذج الـ SaaS والتعدد الإيجاري (Multi-tenancy)، يمكن استثمار النظام تجارياً لتقديم الخدمة لمئات المدارس بتكلفة تشغيلية مُحسَّنة وأداء عالي الاستقرار بفضل معمارية .NET و Vue.js.
